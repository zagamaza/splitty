# Иконка приложения — «Две половины» (5е)

Выбрана пользователем 13.10.2026 из вариантов в стиле «Общий чек»: два чека
внахлёст — чернильный позади, бумажный впереди — на ржаво-оранжевом фоне.
Цвета — токены темы: `#C4502D` (accent), `#FFFDF4` (бумага), `#262722`
(чернила), `#AAA999` / `#5E5E54` (пунктир).

| Файл | Куда идёт |
| --- | --- |
| `icon-ios.svg` | `ios/Splitty/Assets.xcassets/AppIcon.appiconset/icon-1024.png` — 1024×1024, без альфа-канала |
| `icon-android-foreground.svg` | `android/.../mipmap-*/ic_launcher_foreground.png` — 108/162/216/324/432 px, прозрачный; рисунок уменьшен до 0.8, чтобы целиком войти в круг безопасной зоны 66/108 |
| `play-512.png` | иконка карточки в Google Play (загружается в Console вручную) |

Фон адаптивной иконки Android — `@color/ic_launcher_background` = `#C4502D`.

Пересборка: `rsvg-convert -w 1024 -h 1024 icon-ios.svg -o icon-1024.png`
(затем убрать альфа-канал), для Android — те же команды с размерами выше.

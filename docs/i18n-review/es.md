## Расхождений: регистр 0, терминология 11

Расхождение — повод посмотреть, а не приговор: пропуск слова там, где
рядом стоит название в кавычках, для перевода нормален. Приговор тут
один — разнобой: одно и то же русское слово переведено в двух местах
по-разному.

- термин: «расход» → ждали «Gasto»: 'С кем делите расход?' → '¿Con quién lo divides?'
- термин: «группа» → ждали «Grupo»: ' в группе «%@»' → ' en «%@»'
- термин: «группа» → ждали «Grupo»: ' добавил(а) «%@» в группе «%@»' → ' añadió «%1$@» en «%2$@»'
- термин: «группа» → ждали «Grupo»: '%@ добавил вас в группу «%@»' → '%1$@ te añadió a «%2$@»'
- термин: «участник» → ждали «Miembro»: 'Splitty делит каждый расход на участников. Ужин 600 на троих — по 200, такси 300 — по 100.' → 'Splitty divide cada gasto entre los participantes. Una cena de 6,00 € entre tres son 2,00 € cada uno; un taxi de 3,00 €, 1,00 € cada uno.'
- термин: «участник» → ждали «Miembro»: 'Все участники в расчёте' → 'Todos están en paz'
- термин: «участник» → ждали «Miembro»: 'Новые расходы, погашения и приглашения — всё, что делают участники' → 'Nuevos gastos, pagos e invitaciones: todo lo que hacen los participantes'
- термин: «участник» → ждали «Miembro»: 'Расходы делятся между участниками — пока в группе только вы, делить не с кем' → 'Los gastos se reparten entre los participantes: mientras estés solo en el grupo, no hay con quién repartir'
- термин: «участник» → ждали «Miembro»: 'Суммы не пересчитываются — изменится только обозначение, у всех участников группы' → 'Los importes no se convierten: solo cambia el símbolo, para todo el grupo'
- термин: «долг» → ждали «Deudas»: 'Вам вернули долг' → 'Alguien te devolvió dinero'
- термин: «долг» → ждали «Deudas»: 'Все долги погашены' → 'Todo saldado'

# Выборка переводов: pt-BR

## Термины (эталон из каталога)

- группа → **Grupo**
- долг → **Dívidas**
- доля → **cota**
- расход → **Despesa**
- участник → **Participante**

## Расхождений: регистр 0, терминология 16

Расхождение — повод посмотреть, а не приговор: пропуск слова там, где
рядом стоит название в кавычках, для перевода нормален. Приговор тут
один — разнобой: одно и то же русское слово переведено в двух местах
по-разному.

- термин: «расход» → ждали «Despesa»: 'С кем делите расход?' → 'Com quem você divide?'
- термин: «группа» → ждали «Grupo»: ' в группе «%@»' → ' em “%@”'
- термин: «группа» → ждали «Grupo»: ' добавил(а) «%@» в группе «%@»' → ' adicionou “%1$@” em “%2$@”'
- термин: «группа» → ждали «Grupo»: '%@ добавил вас в группу «%@»' → '%1$@ adicionou você a “%2$@”'
- термин: «группа» → ждали «Grupo»: 'Расходы делятся между участниками — пока в группе только вы, делить не с кем' → 'As despesas são divididas entre os participantes — enquanto só você estiver aqui, não há com quem dividir'
- термин: «участник» → ждали «Participante»: '«Поровну» отбросит позиции чека и поделит сумму на всех участников поровну. Вернуть можно кнопкой «Отменить»' → '“Igualmente” descarta os itens do recibo e divide o valor por igual entre todos. Você pode voltar atrás em “Desfazer”'
- термин: «участник» → ждали «Participante»: 'Диаграмма долей участников в оплатах' → 'Gráfico da participação de cada um nos pagamentos'
- термин: «участник» → ждали «Participante»: 'Суммы не пересчитываются — изменится только обозначение, у всех участников группы' → 'Os valores não são convertidos — muda só o símbolo, para todo o grupo'
- термин: «долг» → ждали «Dívidas»: 'Все долги погашены' → 'Tudo quitado'
- термин: «долг» → ждали «Dívidas»: 'Нет соединения. Погашение долга доступно только онлайн' → 'Sem conexão. O acerto de contas só funciona online'
- термин: «доля» → ждали «cota»: 'Ваша доля 300 ₽ уходит одним переводом, а не двумя: Splitty сводит долги внутри группы.' → 'Sua parte de R$ 30,00 sai em uma transferência, não em duas: o Splitty compensa as dívidas dentro do grupo.'
- термин: «доля» → ждали «cota»: 'Ваша доля за вечер' → 'Sua parte da noite'
- термин: «доля» → ждали «cota»: 'Диаграмма долей участников в оплатах' → 'Gráfico da participação de cada um nos pagamentos'
- термин: «доля» → ждали «cota»: 'Расход переименовали или добавили фото — сумма и ваша доля не изменились' → 'Uma despesa foi renomeada ou ganhou uma foto — o valor e a sua parte não mudaram'
- термин: «доля» → ждали «cota»: 'ваша доля' → 'sua parte'
- термин: «доля» → ждали «cota»: 'ваша доля: 200 + 100' → 'sua parte: R$ 20,00 + R$ 10,00'

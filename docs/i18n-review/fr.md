# Выборка переводов: fr

## Термины (эталон из каталога)

- группа → **Groupe**
- долг → **Dettes**
- доля → **part**
- расход → **Dépense**
- участник → **Membre**

## Расхождений: регистр 0, терминология 14

Расхождение — повод посмотреть, а не приговор: пропуск слова там, где
рядом стоит название в кавычках, для перевода нормален. Приговор тут
один — разнобой: одно и то же русское слово переведено в двух местах
по-разному.

- термин: «расход» → ждали «Dépense»: 'Добавить расход' → 'Ajouter'
- термин: «расход» → ждали «Dépense»: 'С кем делите расход?' → 'Avec qui partagez-vous\xa0?'
- термин: «группа» → ждали «Groupe»: ' в группе «%@»' → ' dans «\xa0%@\xa0»'
- термин: «группа» → ждали «Groupe»: ' добавил(а) «%@» в группе «%@»' → ' a ajouté «\xa0%1$@\xa0» dans «\xa0%2$@\xa0»'
- термин: «группа» → ждали «Groupe»: '%@ добавил вас в группу «%@»' → '%1$@ t’a ajouté à «\xa0%2$@\xa0»'
- термин: «участник» → ждали «Membre»: 'Splitty делит каждый расход на участников. Ужин 600 на троих — по 200, такси 300 — по 100.' → 'Splitty répartit chaque dépense entre les participants. Un dîner à 6,00 € pour trois, c’est 2,00 € chacun ; un taxi à 3,00 €, 1,00 € chacun.'
- термин: «участник» → ждали «Membre»: 'Все участники в расчёте' → 'Tout le monde est quitte'
- термин: «участник» → ждали «Membre»: 'Новые расходы, погашения и приглашения — всё, что делают участники' → 'Nouvelles dépenses, remboursements et invitations — tout ce que font les participants'
- термин: «участник» → ждали «Membre»: 'Расходы делятся между участниками — пока в группе только вы, делить не с кем' → 'Les dépenses se partagent entre participants — tant que vous êtes seul dans le groupe, il n’y a personne avec qui partager'
- термин: «участник» → ждали «Membre»: 'Суммы не пересчитываются — изменится только обозначение, у всех участников группы' → 'Les montants ne sont pas convertis — seul le symbole change, pour tout le groupe'
- термин: «долг» → ждали «Dettes»: 'Вам вернули долг' → "Quelqu'un vous a remboursé"
- термин: «долг» → ждали «Dettes»: 'Все долги погашены' → 'Tout est réglé'
- термин: «долг» → ждали «Dettes»: 'Нет соединения. Погашение долга доступно только онлайн' → "Pas de connexion. Le règlement ne fonctionne qu'en ligne"
- термин: «долг» → ждали «Dettes»: 'Погашение долга' → 'Remboursement'

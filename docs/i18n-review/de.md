## Расхождений: регистр 0, терминология 14

Расхождение — повод посмотреть, а не приговор: пропуск слова там, где
рядом стоит название в кавычках, для перевода нормален. Приговор тут
один — разнобой: одно и то же русское слово переведено в двух местах
по-разному.

- термин: «расход» → ждали «Ausgabe»: 'Добавить расход' → 'Hinzufügen'
- термин: «группа» → ждали «Gruppe»: ' в группе «%@»' → ' in „%@“'
- термин: «группа» → ждали «Gruppe»: ' добавил(а) «%@» в группе «%@»' → ' hat „%1$@“ in „%2$@“ hinzugefügt'
- термин: «группа» → ждали «Gruppe»: '%@ добавил вас в группу «%@»' → '%1$@ hat dich zu „%2$@“ hinzugefügt'
- термин: «участник» → ждали «Mitglied»: 'Splitty делит каждый расход на участников. Ужин 600 на троих — по 200, такси 300 — по 100.' → 'Splitty teilt jede Ausgabe unter den Teilnehmern auf. Abendessen für 6,00 € durch drei sind je 2,00 €, Taxi für 3,00 € je 1,00 €.'
- термин: «участник» → ждали «Mitglied»: 'Все участники в расчёте' → 'Alle sind quitt'
- термин: «участник» → ждали «Mitglied»: 'Новые расходы, погашения и приглашения — всё, что делают участники' → 'Neue Ausgaben, Rückzahlungen und Einladungen — alles, was die Teilnehmer tun'
- термин: «участник» → ждали «Mitglied»: 'Расходы делятся между участниками — пока в группе только вы, делить не с кем' → 'Ausgaben werden unter den Teilnehmern geteilt — solange du allein in der Gruppe bist, gibt es niemanden zum Teilen'
- термин: «участник» → ждали «Mitglied»: 'Суммы не пересчитываются — изменится только обозначение, у всех участников группы' → 'Beträge werden nicht umgerechnet — es ändert sich nur das Symbol, für alle in der Gruppe'
- термин: «долг» → ждали «Schulden»: 'Вам вернули долг' → 'Jemand hat dir Geld zurückgezahlt'
- термин: «долг» → ждали «Schulden»: 'Все долги погашены' → 'Alles ausgeglichen'
- термин: «долг» → ждали «Schulden»: 'Нет соединения. Погашение долга доступно только онлайн' → 'Keine Verbindung. Begleichen geht nur online'
- термин: «Apple ID» потерян: '%@ за %@. Подписка продлевается автоматически, отменить можно в настройках Apple ID' → '%1$@ pro %2$@. Verlängert sich automatisch, Kündigung in den Apple-ID-Einstellungen'

## Расхождений: регистр 0, терминология 11

Расхождение — повод посмотреть, а не приговор: пропуск слова там, где
рядом стоит название в кавычках, для перевода нормален. Приговор тут
один — разнобой: одно и то же русское слово переведено в двух местах
по-разному.

- термин: «расход» → ждали «Spesa»: 'С кем делите расход?' → 'Con chi dividi?'
- термин: «группа» → ждали «Gruppo»: ' в группе «%@»' → ' in “%@”'
- термин: «группа» → ждали «Gruppo»: ' добавил(а) «%@» в группе «%@»' → ' ha aggiunto “%1$@” in “%2$@”'
- термин: «группа» → ждали «Gruppo»: '%@ добавил вас в группу «%@»' → '%1$@ ti ha aggiunto a “%2$@”'
- термин: «группа» → ждали «Gruppo»: 'Расходы делятся между участниками — пока в группе только вы, делить не с кем' → 'Le spese si dividono tra i partecipanti: finché ci sei solo tu, non c’è con chi dividere'
- термин: «участник» → ждали «Partecipante»: 'Диаграмма долей участников в оплатах' → 'Grafico della quota di ciascuno nei pagamenti'
- термин: «участник» → ждали «Partecipante»: 'Суммы не пересчитываются — изменится только обозначение, у всех участников группы' → 'Gli importi non vengono convertiti: cambia solo il simbolo, per tutto il gruppo'
- термин: «долг» → ждали «Debiti»: 'Все долги погашены' → 'Tutto saldato'
- термин: «долг» → ждали «Debiti»: 'Нет соединения. Погашение долга доступно только онлайн' → 'Nessuna connessione. Saldare funziona solo online'
- термин: «Apple ID» потерян: '%@ за %@. Подписка продлевается автоматически, отменить можно в настройках Apple ID' → '%1$@ ogni %2$@. Si rinnova automaticamente; puoi disdire quando vuoi nelle impostazioni dell’ID Apple'
- термин: «Apple ID» потерян: 'Подписка продлевается автоматически. Отменить можно в настройках Apple ID' → 'Si rinnova automaticamente. Puoi disdire quando vuoi nelle impostazioni dell’ID Apple'

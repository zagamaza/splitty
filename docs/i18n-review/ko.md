# Выборка переводов: ko

## Термины (эталон из каталога)

- группа → **그룹**
- долг → **빚**
- доля → **몫**
- расход → **지출**
- участник → **참여자**

## Расхождений: регистр 0, терминология 11

Расхождение — повод посмотреть, а не приговор: пропуск слова там, где
рядом стоит название в кавычках, для перевода нормален. Приговор тут
один — разнобой: одно и то же русское слово переведено в двух местах
по-разному.

- термин: «расход» → ждали «지출»: 'Поездка, съёмная квартира или один ужин. Платит кто-то один, а расход делят все.' → '여행, 임대한 집, 한 번의 저녁. 한 사람이 결제하고 모두가 나눕니다.'
- термин: «расход» → ждали «지출»: 'С кем делите расход?' → '누구와 나누십니까?'
- термин: «группа» → ждали «그룹»: ' в группе «%@»' → '「%@」에서'
- термин: «группа» → ждали «그룹»: ' добавил(а) «%@» в группе «%@»' → '「%2$@」에 「%1$@」을(를) 추가했습니다'
- термин: «группа» → ждали «그룹»: '%@ добавил вас в группу «%@»' → '%1$@ 님이 회원님을 「%2$@」에 추가했습니다'
- термин: «группа» → ждали «그룹»: 'Расходы делятся между участниками — пока в группе только вы, делить не с кем' → '지출은 참여자끼리 나눕니다. 지금은 회원님뿐이라 나눌 상대가 없습니다'
- термин: «участник» → ждали «참여자»: '%lld участников' → '%lld명'
- термин: «участник» → ждали «참여자»: 'Суммы не пересчитываются — изменится только обозначение, у всех участников группы' → '금액은 환산되지 않습니다. 표기만 그룹 전원에게 바뀝니다'
- термин: «долг» → ждали «빚»: 'Все долги погашены' → '모두 정산 완료'
- термин: «долг» → ждали «빚»: 'Нет соединения. Погашение долга доступно только онлайн' → '연결이 없습니다. 정산은 온라인에서만 가능합니다'
- термин: «доля» → ждали «몫»: 'Диаграмма долей участников в оплатах' → '참여자별 결제 비율 차트'

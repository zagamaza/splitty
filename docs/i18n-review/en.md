# Выборка переводов: en

## Термины (эталон из каталога)

- группа → **Group**
- долг → **Debts**
- доля → **share**
- расход → **Expense**
- участник → **Member**

## Расхождений: регистр 0, терминология 12

Расхождение — повод посмотреть, а не приговор: пропуск слова там, где
рядом стоит название в кавычках, для перевода нормален. Приговор тут
один — разнобой: одно и то же русское слово переведено в двух местах
по-разному.

- термин: «расход» → ждали «Expense»: 'С кем делите расход?' → 'Who are you splitting with?'
- термин: «группа» → ждали «Group»: ' в группе «%@»' → ' in “%@”'
- термин: «группа» → ждали «Group»: ' добавил(а) «%@» в группе «%@»' → ' added “%1$@” in “%2$@”'
- термин: «группа» → ждали «Group»: '%@ добавил вас в группу «%@»' → '%1$@ added you to “%2$@”'
- термин: «группа» → ждали «Group»: 'В группе только вы' → "You're the only one here"
- термин: «группа» → ждали «Group»: 'Расходы делятся между участниками — пока в группе только вы, делить не с кем' → 'Expenses are split between members — while you’re the only one here, there’s no one to split with'
- термин: «участник» → ждали «Member»: 'Все участники в расчёте' → 'Everyone is settled up'
- термин: «участник» → ждали «Member»: 'Суммы не пересчитываются — изменится только обозначение, у всех участников группы' → "Amounts aren't converted — only the symbol changes, for everyone in the group"
- термин: «долг» → ждали «Debts»: 'Вам вернули долг' → 'Someone paid you back'
- термин: «долг» → ждали «Debts»: 'Все долги погашены' → 'All settled up'
- термин: «долг» → ждали «Debts»: 'Группы, расходы и долги остаются бесплатными' → 'Groups, expenses and balances stay free'
- термин: «долг» → ждали «Debts»: 'Нет соединения. Погашение долга доступно только онлайн' → 'No connection. Settling up works only online'

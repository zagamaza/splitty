- доля → **負担分**
- расход → **支出**
- участник → **メンバー**

## Расхождений: регистр 0, терминология 23

Расхождение — повод посмотреть, а не приговор: пропуск слова там, где
рядом стоит название в кавычках, для перевода нормален. Приговор тут
один — разнобой: одно и то же русское слово переведено в двух местах
по-разному.

- термин: «расход» → ждали «支出»: 'С кем делите расход?' → '誰と分けますか？'
- термин: «группа» → ждали «グループ»: ' в группе «%@»' → '「%@」で'
- термин: «группа» → ждали «グループ»: ' добавил(а) «%@» в группе «%@»' → 'さんが「%2$@」に「%1$@」を追加しました'
- термин: «группа» → ждали «グループ»: '%@ добавил вас в группу «%@»' → '%1$@ さんがあなたを「%2$@」に追加しました'
- термин: «группа» → ждали «グループ»: 'Расходы делятся между участниками — пока в группе только вы, делить не с кем' → '支出はメンバーで分割されます。今はあなただけなので、分ける相手がいません'
- термин: «участник» → ждали «メンバー»: '%lld участников' → '%lld 人'

- термин: «участник» → ждали «メンバー»: 'Все участники в расчёте' → '全員が精算済みです'
- термин: «участник» → ждали «メンバー»: 'На вас записано расходов: %lld. Уберите себя из них, а если платили вы — смените плательщика или удалите расход. Править расходы может любой участник' → 'あなたは %lld 件の支出に入っています。そこから自分を外してください。支払ったのがあなたなら、支払者を変えるか支出を削除します。支出は誰でも編集できます'
- термин: «участник» → ждали «メンバー»: 'Суммы не пересчитываются — изменится только обозначение, у всех участников группы' → '金額は換算されません。表記だけがグループ全員で変わります'

# Онбординг: приложение объясняет себя

## Overview

Находка 25 аудита: онбординга нет ни в каком виде. Всё объяснение продукта — пять слов под логотипом («Делите расходы с друзьями», `LoginView.swift:164`). Сразу после регистрации человек попадает на вкладку «Друзья» с надписью «Пока нет друзей» (`MainTabView.swift:26`, `MainScaffold.kt:418`).

Первая фраза, которую читает новый аккаунт, — отрицание, и оно ссылается на понятие, с которым человек ещё не знаком. Неочевидные правила продукта — что чек и голос распознаёт сервер, что пригласить можно только своего друга, что нельзя выйти из группы с непогашенными расходами, что приложение только записывает долги и не переводит деньги — человек узнаёт, только упёршись в них.

Это вынесено отдельным планом из `20260812-audit-fixes.md`: там исправления, здесь продуктовая работа с текстами и экранами. Порядок — сначала исправления, потом это.

## Solution Overview

**Объяснять в момент, а не заранее.** Карусель из пяти экранов перед входом человек пролистывает не читая. Поэтому основной вес — на контекстных объяснениях: пустое состояние говорит, зачем этот экран; правило всплывает там, где в него упираются. Разовый экран приветствия остаётся, но короткий и пропускаемый.

**Первый экран — группы, а не друзья.** Группа — единица продукта: в ней расходы, в неё зовут, её создают. Друзья — вспомогательная сущность. Новый аккаунт должен видеть «создайте группу», а не «пока нет друзей».

**Ни одного пустого состояния, которое начинается с отрицания.** Заголовок говорит, что здесь будет и зачем; действие — рядом.

## Technical Details

- флаг «приветствие показано» хранится там же, где остальные локальные предпочтения: iOS — `UserDefaults` рядом с прочими флагами первого показа, Android — `SessionStore`/DataStore
- флаг привязан к аккаунту, а не к установке: смена аккаунта на том же устройстве показывает приветствие заново
- приветствие показывается только после успешного входа и только при пустом списке групп — человек, вернувшийся после переустановки, его не видит

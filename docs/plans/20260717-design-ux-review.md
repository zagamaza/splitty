Ревью тремя независимыми проходами (табы/логин/друзья/профиль · экраны групп ·
AI-флоу расхода) по коду + PNG-рендерам. Вердикт: дизайн заметно выше среднего

«несчастливые пути» (ошибки/зависания), последняя миля ключевых сценариев.

## CRITICAL

1. **Dev-вход и поле «Сервер» в релизной сборке** — `LoginView.swift:150–160,
   191–206`, `AccountView.swift:242–260`. Любой может войти под чужим
   Telegram ID; поле сервера подрывает доверие. → `#if DEBUG`.
2. **Оверлей «Распознаю…» без отмены и таймаута** — `AddExpenseView.swift:549`.
   Завис Gemini — пользователь заперт (перекрыт даже навбар). → «Отмена»
   после ~3 с + таймаут запроса; аудио уже в `lastAudio`, повтор бесплатен.
3. **Dynamic Type отсутствует во всём приложении** — все шрифты
   `.system(size: N)` без `relativeTo`. → чинится централизованно в
   DesignSystem/MoneyText/sectionHeaderStyle (`relativeTo:` + `@ScaledMetric`).
4. **Дубль «Уведомления» в профиле** — `AccountView.swift:127–129`:
   NavigationLink и Toggle с одним названием подряд; выключенный тумблер +
   включённые категории = противоречие. → master-toggle внутрь экрана категорий.
5. **Empty state ссылается на несуществующую кнопку** —
   `GroupDetailView.swift:385` «кнопкой „+ Расход“» (кнопки нет, есть «+» в
   табах). → исправить текст + кнопка в `actions:`.

## MAJOR (по влиянию)

Онбординг и ключевые пути:
- Логин: нет кнопки «Открыть бота» (`tg://resolve?domain=split_money_bot`)
  — главный friction-момент (`LoginView.swift:108`).
- Экран друга: видно «Вы должны 800 ₽», но НЕТ действия «Погасить» —
  надо догадаться идти через группу (`FriendDetailView.swift`).
- Empty states «Группы» и «Друзья» без кнопок действия — тупики новичка
  (`GroupsListView.swift:117`, `FriendsListView.swift:92`).
- Меню «…» с единственным пунктом «Присоединиться по коду» прячет
  onboarding-действие (`GroupsListView.swift:18`).

AI-флоу:

  «Повторить» нет (`AddExpenseViewModel.swift:~405`).

  (`AddExpenseView.swift:1121`).

- Экран «Записано»: фото визуально главнее «Распознать» — иерархия
  перевёрнута (`AddExpenseView.swift:206`).
- Alert про доступ к микрофону без кнопки «Открыть Настройки»
  (`AddExpenseView.swift:944`).
- Hold-to-talk без VoiceOver-альтернативы → toggle-режим при VO

Консистентность поведения:

  GroupBalancesView:55 — одна кнопка, два поведения.
- Кнопка «Погасить» — три визуальных реализации (ручная капсула / softChip /
  свой стиль). Кнопка «Повторить» — тоже три вида. → единые компоненты.
- Ошибки архива групп глотаются: alert привязан к закрытому пушем экрану
  (`GroupsListView.swift:296` + ViewModel:83,96).
- Вечный спиннер секции «Валюта» при упавшей загрузке без retry
  (`GroupSettingsView.swift:261`).
- Смена валюты группы: мгновенно, для всех, без подтверждения, без
  объяснения «суммы не пересчитываются» (`GroupSettingsView.swift:153`).
- «Итоги» в embedded-режиме не обновляются после добавления расхода
  (нет dataVersion/refreshable) (`GroupTotalsView.swift:29`).
- Иконки стат-плиток тонированы палитрой УЧАСТНИКОВ — ломает язык дата-виза
  (`GroupTotalsView.swift:189`).
- Фото чека в деталях операции без пинч-зума (`OperationDetailView.swift:419`).
- Фильтр «Только мои» — toggle, неотличимый от кнопки, VO не сообщает

- Безымянная вкладка-заглушка под «+» ловит фокус VoiceOver

- SettleUp: два leading-элемента в тулбаре («Отмена» + голый chevron)
  (`SettleUpView.swift:47`).
- «1 неотправленных операций» — плюрализация (`AccountView.swift:77`,
  `GroupDetailView.swift:232`).

## Систематические паттерны (чинятся один раз)

- **Словарь нулевого баланса**: «расчёт» / «в расчёте» / «Вы рассчитались» /
  «Все долги погашены» — 4 формулировки одного состояния. Нужен глоссарий
  (по аналогии с MoneyText для цвета).
- **Хептики не по контракту ДС**: `tap()` нет на переключениях (фильтры,
  сегменты, «+»), `warning()` до нуджа микрофона не использовался нигде.
- **Сырые `error.localizedDescription`** в 6+ alert'ах → единый маппер
  ошибок + модификатор `.errorAlert()`.
- **Reduce Motion в ДС**: spring/numericText в DesignSystem не гейтятся
  (в AI-флоу — гейтятся, перенести паттерн).
- **Гендер**: «Я заплатил», «Кто такой „Маша“?» → безличные формы.
- **Разнобой отступов hairline-разделителей**: 62/64/52/16 → константа.
- **«туса»** в текстах уведомлений vs «группа» везде → «группа».

## Сильные стороны (сохранить как эталон)

- Дизайн-система соблюдается: surfaceCard/softChip/primaryPill/MoneyText,
  ноль hex в экранах; тёмная тема через адаптивные токены + receiptPaper.
- Офлайн: глобальный баннер, outbox с бейджами «не отправлено», подпись
  «без учёта N неотправленных», предупреждение при выходе с несинхронным.
- AI-флоу: телеграм-оверлей записи (замок/отмена/кольцо лимита/karaoke),
  нудж вместо мёртвых кнопок, метафора чека с пунктирными «требует ответа»,
  подсветка изменённых строк + undo голосовой правки.
- Дата-виз итогов: CVD-палитра, один человек = один цвет, direct labels.
- Подтверждение удаления операции с объяснением последствий; оптимистичные
  настройки с откатом; защита от двойного тапа на платеже.
